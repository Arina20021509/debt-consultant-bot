# Бот-консультант для сервиса по списанию долгов

Демо-проект: AI-консультант на GigaChat, который отвечает клиентам по базе знаний компании (RAG), не выдумывает ответы и оформляет заявку на консультацию с выгрузкой в Excel. Качество ответов проверяется автоматически на наборе тестовых вопросов.

Автор: Арина Бабич. Раньше я внедряла голосовых роботов холодного обзвона для сервиса по списанию долгов (9 роботов, 100–150 тыс. звонков в месяц, рост конверсии в заявку с 2,3% до 4,6%). Этот проект — следующий шаг: тот же клиентский сценарий, но на LLM.

## Задача

| | |
|---|---|
| **Пользователь** | Человек с долгами, который хочет понять, можно ли их списать, и боится ошибиться |
| **Проблема** | Вопросы типовые (сроки, цены, последствия, документы), но юристы тратят на них время, а ночью и в выходные ответить некому |
| **Сценарий** | Клиент задаёт вопросы в чате → бот отвечает только по проверенной базе знаний → если клиент готов, бот собирает данные и передаёт заявку юристу |
| **MVP** | Консольный чат: ответы по базе знаний, квалификация заявки, выгрузка в Excel, автотест качества |
| **Метрики** | Точность поиска по базе, доля ответов с правильными фактами, доля честных отказов на вопросы вне базы |

## Как устроено

```
Вопрос клиента
   │
   ├─ хочет оставить заявку? ── да ──▶ Квалификация (workflow + LLM) ──▶ data/leads.xlsx
   │                                    вопросы задаёт код, LLM разбирает свободные ответы,
   │                                    предварительную оценку для юриста считает код по правилам
   нет
   │
   ▼
Поиск по базе знаний (эмбеддинги GigaChat, косинусная близость, top-4 фрагмента)
   │
   ▼
GigaChat: роль консультанта + правила + найденные фрагменты + few-shot примеры
   │
   ▼
Ответ только по базе знаний или «уточню у юриста»
```

**Принципы:**
- **LLM понимает, код решает.** Модель отвечает на вопросы и разбирает свободный текст. Условия вроде «долг от 25 000 до 1 000 000 ₽» проверяет обычный код, а не модель.
- **Не выдумывать.** Если ответа нет в базе, бот говорит «уточню у юриста» и предлагает консультацию.
- **Без юридических обещаний.** Бот не говорит клиенту, спишут ли долги: это решает юрист. Предварительная оценка видна только юристу в Excel.

**Техники промптинга:** role prompting (роль и правила консультанта), grounding (ответ только по найденным фрагментам), few-shot (примеры ответа, когда информация есть и когда её нет), низкая temperature для стабильности.

## Структура

| Файл | Что делает |
|---|---|
| `knowledge/` | База знаний: 5 документов, 31 фрагмент |
| `bot/kb.py` | Нарезка базы на фрагменты, эмбеддинги, поиск |
| `bot/prompts.py` | Системный промпт и few-shot примеры |
| `bot/llm.py` | Подключение к GigaChat API |
| `bot/qualify.py` | Квалификация заявки и выгрузка в Excel |
| `bot/chat.py` | Консольный чат |
| `bot/evaluate.py` | Автотест качества |
| `tests/questions.csv` | 32 тестовых вопроса: 26 по базе знаний и 6 вне её |

## Качество

Результаты прогона `python -m bot.evaluate`:

| Метрика | Результат |
|---|---|
| Поиск нужного фрагмента (top-4) | будет после первого прогона |
| Ответы с нужными фактами | будет после первого прогона |
| Честные отказы на вопросы вне базы | будет после первого прогона |

## Запуск

1. Получите ключ GigaChat API на [developers.sber.ru](https://developers.sber.ru) (для физлиц есть бесплатный лимит).
2. Установите зависимости и создайте файл с ключом:
   ```
   python -m venv .venv
   .venv\Scripts\activate
   pip install -r requirements.txt
   copy .env.example .env
   ```
   Вставьте ключ в `.env` в строку `GIGACHAT_CREDENTIALS=`.
3. Запустите чат: `python -m bot.chat`
   Команды: `/debug` показывает найденные фрагменты и их оценки, `/заявка` оформляет заявку, `/new` начинает новый диалог.
4. Проверка качества: `python -m bot.evaluate`

## Ограничения

- База знаний написана по общим нормам закона № 127-ФЗ и не является юридической консультацией. Цены и условия компании вымышлены.
- По умолчанию проверка SSL-сертификата GigaChat отключена для простоты демо. Для продакшена укажите сертификат НУЦ Минцифры в `GIGACHAT_CA_BUNDLE`.
